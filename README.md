# Dupe Swap — Minecraft 1.21.11

A small Fabric client mod.

## Commands
- `/dupe on` — starts swapping the selected hotbar slot with offhand at 25 swaps/sec.
- `/dupe off` — stops it.

## Requirements
- Minecraft Java Edition 1.21.11
- Fabric Loader 0.19.5+
- Fabric API 0.139.4+1.21.11
- Java 21

This performs the normal inventory SWAP action. It does not implement or guarantee item duplication on multiplayer servers.
